# 🌿 AI Herbal Anti-Diabetic Scanner

An interactive AI-powered web application that identifies local Nigerian medicinal plants and global botanical species, assessing their anti-diabetic properties, active phytochemicals, local language names, traditional preparation methods, and clinical safety advisories.

## 🚀 Features
* **Real-time Image Recognition:** Uses the PlantNet Botanical API to identify species from leaf, bark, or stem photos.
* **Nigerian Indigenous Knowledge:** Maps species to local language names across Yoruba, Igbo, Hausa, and Efik/Ibibio.
* **Pharmacological & Phytochemical Insights:** Details active compounds (e.g., vernodioside, charantin, chlorogenic acid) and mechanisms of action.
* **Preparation & Synergy Guides:** Outlines traditional aqueous decoctions, cold infusions, dosage guidelines, and herbal combination synergies.
* **Automated Document Export:** Generates downloadable Microsoft Word (`.docx`) clinical/research reports at the click of a button.

## 🛠️ Technical Stack
* **Language:** Python 3.x
* **UI Framework:** Streamlit
* **Computer Vision API:** PlantNet API
* **Image Processing:** Pillow
* **Document Generation:** `python-docx`
